## A post is just a file

The title, date, description, and tags live in the block at the top. The rest is ordinary Markdown.

- A thought
- Another thought
- One more, if you like

> A line you want to set a little apart from the rest.

When a bit of code belongs in the note, fence it off:

```md
---
title: Your title
description: One sentence about the note.
date: 2026-11-16
tags:
  - notes
---
```

Save the file. The next build picks it up.
